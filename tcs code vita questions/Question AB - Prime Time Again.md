# Question AB — Prime Time Again

## Problem Description

A day contains D hours divided into P equal parts. Hours at the same relative position in different parts are equivalent.

Count the equivalent positions for which every corresponding hour is prime.

## Input

D P

## Output

Return the count.

## Constraints

10 <= D < 500
2 <= P < 50
D is divisible by P.

## Example

Input
24 2

Output
3
