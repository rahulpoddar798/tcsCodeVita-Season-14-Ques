# Question K — Coins Distribution

## Problem Description

You are given an integer N and coins of denominations 1, 2, and 5.

Choose a collection of coins such that every value from 1 through N can be formed using a subset of the selected coins. The total value of all selected coins must not exceed N.

Among all valid collections, minimize the total number of coins.

## Input

A single integer N.

## Output

Print the required coin counts according to the problem specification.

## Constraints

0 < N < 1000

## Example

Input

13

Output

6 1 3 2

One valid collection is 5, 2, 2, 2, 1, 1.
