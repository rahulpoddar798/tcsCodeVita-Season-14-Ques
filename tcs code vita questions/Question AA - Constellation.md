# Question AA — Constellation

## Problem Description

You are given a 3 x N matrix containing #, *, and . characters. Each star is represented by a 3 x 3 pattern corresponding to one of A, E, I, O, or U. Stars do not overlap and # separates galaxies.

Identify each vowel pattern from left to right and preserve the # separators.

## Input

N
row1
row2
row3

## Output

Return the decoded vowels and # separators in order.

## Constraints

3 <= N <= 100000

## Example

Output
U#O#I#EA
