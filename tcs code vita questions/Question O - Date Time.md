# Question O — Date Time

## Problem Description

You are given 12 digits. Using each occurrence at most once, construct the latest valid date and time in the year 2018.

The date must be between 01/01 and 12/31 and the time must be between 00:00 and 23:59.

Use all 12 digits exactly once. If no valid date-time can be formed, return 0.

## Input

A comma-separated sequence of 12 digits.

## Output

Return the latest valid date-time in MM/DD HH:MM format, or 0.

## Example

Input
0,0,1,2,2,2,3,5,9,9,9,9

Output
12/30 22:59
