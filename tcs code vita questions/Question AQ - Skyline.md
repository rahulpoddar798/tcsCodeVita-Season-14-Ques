# Question AQ — Skyline

## Problem Description

There are N consecutive buildings with initial heights h1, h2, ..., hN.

You may increase the heights of buildings. After modification, the heights must satisfy:

`|Hi - H(i+1)| <= 1`

for every pair of consecutive buildings.

The total number of floors added must be minimized.

Given the position P of one building, determine the height of that building after the minimum-total-addition modification.

## Input

The original problem provides N and the requested building position P together with the initial building heights.

## Output

Return the resulting minimum-plan height of building P.

## Constraints

The original CodeVita statement restricts the building count and floor heights according to the problem input specification.
