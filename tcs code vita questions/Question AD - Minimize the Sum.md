# Question AD — Minimize the Sum

## Problem Description

You are given an integer array and an integer K. You may perform at most K operations.

In one operation, choose an element and replace it with floor(element / 2).

Return the minimum possible array sum after at most K operations.

## Input

N K
arr1 arr2 ... arrN

## Output

Return the minimum possible final sum.

## Constraints

1 <= N, K <= 100000

## Example

Input
4 3
20 7 5 4

Output
17
