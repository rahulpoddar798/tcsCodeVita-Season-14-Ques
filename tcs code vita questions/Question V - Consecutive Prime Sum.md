# Question V — Consecutive Prime Sum

## Problem Description

Some prime numbers can be represented as the sum of consecutive prime numbers beginning with 2.

For example:
- 5 = 2 + 3
- 17 = 2 + 3 + 5 + 7
- 41 = 2 + 3 + 5 + 7 + 11 + 13

Given N, count how many prime numbers in [3, N] can be represented in this way.

## Input

N

## Output

Return the count.

## Constraints

2 < N <= 12000000000
