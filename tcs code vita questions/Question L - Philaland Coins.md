# Question L — Philaland Coins

## Problem Description

You are given the maximum possible price N of an item in Philaland.

Design a set of coin denominations such that every value from 1 through N can be paid exactly once using at most one coin of each denomination.

Return the minimum number of different coin denominations required.

## Input

The first line contains T, the number of test cases.
Each of the next T lines contains N.

## Output

For each test case, print the minimum number of denominations.

## Constraints

1 <= T <= 100
1 <= N <= 5000

## Example

Input

2
10
5

Output

4
3
