# Question AC — Minimum Gifts

## Problem Description

A company has N employees standing in a line. Each employee has a rank.

Every employee must receive at least one gift. If an employee has a higher rank than an adjacent employee, they must receive more gifts than that neighbor.

Return the minimum total number of gifts required.

## Input

T
For each test case: N followed by the N ranks.

## Output

For each test case, print the minimum total number of gifts.

## Constraints

1 < T < 10
1 < N < 100000
1 < rank < 10^9

## Example

Input
2
5
1 2 1 5 2
2
1 2

Output
7
3
