# Question T — Seating Arrangement

## Problem Description

You are given N seats arranged in a line. O represents an occupied seat and E represents an empty seat.

Move the minimum number of people so that all occupied seats become consecutive.

Return the minimum number of movements and the number of different arrangements that achieve this minimum. If all occupied seats are already consecutive, output 00.

## Input

N
S

## Output

minimumMoves numberOfWays

## Constraints

1 <= N <= 100000

## Example

Input
5
OEOEO

Output
1 2
