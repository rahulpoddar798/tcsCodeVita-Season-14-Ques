# Question AF — Happy Elements

## Problem Description

You are given an integer array A and an integer K.

An element X is happy if there exists another element Y at a different index such that |X - Y| <= K.

Return the total number of happy elements.

## Input

N K
A1 A2 ... AN

## Output

Return the number of happy elements.

## Constraints

1 <= N <= 100000
0 <= K <= 100000
0 <= Ai <= 10^9

## Example

Input
6 3
5 5 7 9 15 2

Output
5
