# Question N — Lift

## Problem Description

A building has M lifts and N lift requests. Each request specifies a source floor and a destination floor.

All requests are known in advance. Assign lifts to requests so that the maximum waiting time among all requests is minimized.

The problem also allows choosing the initial floor of each lift at time 0 according to the original statement's rules.

## Input

The original problem provides the request sequence and lift count according to its specified input format.

## Output

Return the minimum possible maximum waiting time.

## Notes

The complete original problem concerns optimal lift assignment and choosing suitable initial positions.
