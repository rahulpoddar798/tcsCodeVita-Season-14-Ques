# Question AM — Distribute Books

## Problem Description

A school has N students and N books, with each student initially having a different book.

The students exchange books so that after the exchange every student receives a book different from the one they originally had.

Determine the total number of possible exchanges.

Two exchanges are considered different when at least one student receives a different book.

Because the result can be large, return it modulo 1000000007.

## Input

A single integer N, the number of students and books.

## Output

Return the number of valid exchanges modulo 1000000007.

## Constraints

- 1 <= N <= 1000000

## Example

Input
```
4
```

Output
```
9
```

For N = 4, there are 9 valid exchanges in which no student receives their original book.
