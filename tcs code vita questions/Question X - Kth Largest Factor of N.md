# Question X — Kth Largest Factor of N

## Problem Description

Given positive integers N and K, find the K-th largest factor of N. If N has fewer than K factors, return 1.

## Input

N,K

## Output

Return the K-th largest factor, or 1 if fewer than K factors exist.

## Constraints

1 < N < 10^10
1 < K < 600
N has no prime factor greater than 13.

## Example

Input
12,3

Output
4
