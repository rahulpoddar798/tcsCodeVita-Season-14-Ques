# Question U — Polygon With Maximum Area

## Problem Description

You are given N points in a two-dimensional plane. The points are not necessarily given in boundary order.

Construct a polygon using all the points such that the polygon has the maximum possible area.

## Input

N
x1 y1
x2 y2
...
xN yN

## Output

Return the maximum possible area.

## Constraints

1 <= N <= 10

## Example

Input
4
0 0
2 0
0 2
2 2

Output
4
