# Question AS — Concatenating Prime

## Problem Description

Given an integer N, consider every ordered pair of prime numbers p and q such that both p and q are less than or equal to N.

Concatenate the decimal representations of p and q to form a new integer.

For example, concatenating 2 and 3 produces 23.

Count the number of **distinct concatenated results that are prime**.

## Input

A single integer N.

## Output

Return the number of distinct prime numbers that can be obtained by concatenating two primes less than or equal to N.

## Constraints

N <= 70

## Examples

### Example 1

Input
```
10
```

Output
```
4
```

The four primes are 23, 37, 53, and 73.

### Example 2

Input
```
20
```

Output
```
17
```
