# Question Y — String Pair

## Problem Description

You are given N integers. Convert each integer to its English textual representation and count the total number of vowels a, e, i, o, and u. Let this total be D.

Count unordered pairs of distinct elements whose sum equals D. Convert the pair count to its English word representation. If the pair count exceeds 100, return greater 100.

For 100, use the textual form hundred.

## Input

N
A1 A2 ... AN

## Output

Return the pair count in lowercase English, or greater 100.

## Constraints

1 <= N <= 100
1 <= Ai <= 100

## Example

Input
5
1 2 3 4 5

Output
one
