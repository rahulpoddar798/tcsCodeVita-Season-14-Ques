# Question P — Digital Time

## Problem Description

You are given 9 digits. Choose exactly 6 digit occurrences and arrange them to form the maximum valid time.

The valid range is 00:00:01 to 24:00:00.

If no valid time can be formed, return Impossible.

## Input

A comma-separated sequence of 9 digits.

## Output

Return the maximum valid time in HH:MM:SS format, or Impossible.

## Example

Input
0,0,1,1,3,5,6,7,7

Output
17:57:36
