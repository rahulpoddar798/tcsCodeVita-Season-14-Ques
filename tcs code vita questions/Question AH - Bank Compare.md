# Question AH — Bank Compare

## Problem Description

Two banks offer loans with different interest-rate schedules. Each schedule is divided into slabs, each specifying the number of years and annual interest rate.

For each bank, calculate the total repayment cost using the EMI formula specified by the original problem, taking into account the interest-rate slabs over the loan tenure.

Return the bank with the lower total cost.

## Input

P
T
Bank A slab information
Bank B slab information

The exact slab layout follows the original problem statement.

## Output

Bank A or Bank B.

## Constraints

1 <= P <= 1000000
1 <= T <= 50
1 <= number of slabs <= 30
