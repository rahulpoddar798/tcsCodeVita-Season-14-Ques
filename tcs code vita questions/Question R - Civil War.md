# Question R — Civil War

## Problem Description

There are N Avengers standing in a line, each with an integer power value.

Two players alternately choose Avengers. On each turn a player may choose one or more consecutive Avengers from one side of the remaining line and cannot switch sides during the same turn.

Both players play optimally. Determine the difference between the powers obtained by the two players.

## Input

N
P1 P2 ... PN

## Output

Return the resulting difference.

## Constraints

1 <= N <= 1000000
-1000000000 <= Pi <= 1000000000

## Example

Input
5
2 -7 8 -1 20

Output
2

## Note

The archived public statement is poorly formatted about some turn details; no additional game assumptions are added here.
