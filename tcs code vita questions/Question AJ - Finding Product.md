# Question AJ — Finding Product

## Problem Description

You are given a set of N positive integers and two small prime numbers P and Q. P and Q may be equal.

Count the number of subsets whose product is divisible by:

`P x Q`

Because the number of valid subsets can be very large, return the answer modulo 1009.

## Input

The first line contains three comma-separated integers:

`N, P, Q`

The second line contains N comma-separated positive integers.

## Output

Return the number of subsets whose product is divisible by P x Q, modulo 1009.

## Constraints

- N <= 300
- P <= 50
- Q <= 50
- Each given integer <= 10000

## Example

The input consists of N, P, Q followed by the N values according to the format above.
